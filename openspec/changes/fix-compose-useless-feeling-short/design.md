## Context

冲动消费分支条件两侧均含「没用」，导致无消费语境的「好没用」误命中消费后悔话术。见 proposal.md - Why。上一轮 `fix-compose-inferiority-short` 明确未修此误路由，本轮单点修正。

## Goals / Non-Goals

**Goals**
- 无消费语境的 ≤12 字「没用」短句走自我否定共情，不套用「管不住手 / 后悔」话术
- 含「管不住手 / 乱花钱」等消费语境的既有路径保持不变
- compose 与 mock 场景路径对齐

**Non-Goals**
- 不扩展「被裁 / 被鸽 / 愧疚 / 摆烂」等其他缺口
- 不改调度频率、安全策略、记忆召回、avatar 映射
- 不改动「自卑」专用话术分支本身（可并列扩展「没用」分流）

## Decisions

1. **收紧冲动消费语境判定**：第二侧 `any` 去掉单独的「没用」，消费语境须含「乱花钱 / 钱 / 买 / 花 / 手」或「管不住」等真实消费线索；「好没用」单独不再命中该分支。
2. **短句自我否定分流**：在比较/自我怀疑分支（或紧邻其前）为无消费语境的 ≤12 字「没用」追加专用话术（先接住自我否定、不急着贴标签），与「自卑」短句模式一致；话术避免「后悔 / 管不住手 / 乱花钱」。
3. **mock 对齐**：mock 冲动消费条件与短句分流同步修改，保证 CI mock 路径与 compose 一致。
4. **回归保护**：保留既有 `test_compose_impulse_regret_self_blame`（「觉得自己好没用，管不住手」）断言，确保消费语境不被误伤。

## Risks / Trade-offs

- [长句「我觉得自己好没用」>12 字] → 本轮仅覆盖 ≤12 字短句；更长句仍可依赖 persona 侧重「自我怀疑/比较」或通用负面
- [「用不上」含「用不」误伤] → 关键词为「没用」子串；「用不上」不含「没用」，不受影响
- [消费语境漏判] → 「管不住手」仍含「管不住」+「手」，继续命中冲动消费分支
