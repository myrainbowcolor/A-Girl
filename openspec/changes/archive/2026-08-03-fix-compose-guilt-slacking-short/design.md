## Context

See proposal.md - Why。scene_first 路径优先调用 `compose_contextual_reply`；未命中分支时落入问卷式 open 兜底。`mock.py` 对未覆盖关键词常返回空串。既有冲动消费分支条件为（乱花钱/管不住/没用/后悔）∧（钱/买/手/花），因此纯短句「好后悔」「愧疚」「内疚」「摆烂」均未命中。

## Goals / Non-Goals

**Goals:**
- ≤12 字愧疚/内疚/摆烂/无消费后悔短句命中专用共情分支
- compose 与 mock 话术对齐
- 既有冲动消费后悔路径回归通过
- 最小 diff，可测可回滚

**Non-Goals:**
- 不改调度频率、安全策略、avatar、记忆/编排主路径
- 不扩其他未点名缺口
- 不新增 dialogue_quality 场景（基线已 26/26）

## Decisions

1. **关键词**：`愧疚` / `内疚` / `摆烂` / `后悔`；后悔须排除消费线索（钱/买/手/花/乱花钱/管不住），避免抢走冲动消费分支。
2. **位置**：置于冲动消费分支之后、通用 open 兜底之前；消费语境「好后悔买了」仍先由消费分支命中。
3. **分流**：按「摆烂」「愧疚/内疚」「后悔」轻分流话术，避免单一 `_pick` 混搭导致「摆烂了」抽到「愧疚」话术，或「好后悔」抽到「乱花钱/管不住手」话术。
4. **语气**：接住内疚/自我责备或摆烂无力感，至多一个问句；不以「嗯」开头；不说教、不贴「没用」标签。

## Risks / Trade-offs

- [与消费后悔抢占] 「好后悔买了」含买 → 仍走冲动消费；新分支在其后且后悔需无消费线索
- [话术混搭] 单池乱抽 → 按关键词分流
- [「后悔」过宽] 限制 ≤12 字 + 无消费线索，降低误伤长句
