## Context

See proposal.md - Why。scene_first 路径优先调用 `compose_contextual_reply`；未命中分支时落入问卷式 open 兜底。`mock.py` 对未覆盖关键词常返回空串；含「累」的短句可能落入泛化「不太好受」而缺乏针对性。既有「心累」覆盖「心累透了」，但不覆盖「累透了」「累趴了」；「提不起劲」不覆盖「不想动 / 懒得动」；「无所谓了 / 没盼头」无专用分支。

## Goals / Non-Goals

**Goals:**
- ≤12 字累透了/累趴了/不想动/懒得动/没盼头/无所谓了短句命中专用共情分支
- compose 与 mock 话术对齐，按关键词轻分流
- 「心累透了」仍走既有心累路径
- 既有「好累啊」「提不起劲」「心累」路径回归通过
- 最小 diff，可测可回滚

**Non-Goals:**
- 不改调度频率、安全策略、avatar、记忆/编排主路径
- 不把「无所谓了 / 没盼头」纳入危机关键词
- 不新增 dialogue_quality 场景（基线已 26/26）
- 不扩「提不起精神来了 / 什么都不想干」等未点名缺口（「什么都不想干」若后续需要另开 change）
- 不改 `is_minimal_fatigue_utterance` 白名单（本轮走专用 compose 分支）

## Decisions

1. **关键词**：`累透` / `累趴` / `不想动` / `懒得动` / `没盼头` / `没啥盼头` / `无所谓了`。不用裸「无所谓」（避免中性敷衍误伤）。
2. **位置**：置于废了/完了/提不起兴趣分支之后、短句烦躁 / 通用 open 之前（且远在心累分支之后，确保「心累透了」先命中心累）。
3. **分流**：按「累透/累趴」「不想动/懒得动」「没盼头」「无所谓了」轻分流话术。
4. **语气**：接住力竭、动不起来、没盼头或无所谓的泄气感，至多一个问句；不以「嗯」开头；不说教；不输出危机热线。
5. **mock**：同步场景分支，但须置于泛化「累」低落分支（「不太好受」套话）之前，否则「累透了/累趴了」会被抢先；`_VENT` / `_user_tone` 补充同关键词。

## Risks / Trade-offs

- [与心累重叠] 「心累透了」含「累透」→ 依赖既有心累分支更早命中；回归用例保留
- [危机误报] 「无所谓了 / 没盼头」口语 ≠ 自伤 → 不改 `safety.py`
- [「无所谓」过宽] 仅匹配「无所谓了」，不用裸「无所谓」
- [与极简疲惫重叠] 「累透了」不进 `is_minimal_fatigue_utterance`，走专用分支避免泛化套话
- [话术混搭] 单池乱抽 → 按关键词分流
