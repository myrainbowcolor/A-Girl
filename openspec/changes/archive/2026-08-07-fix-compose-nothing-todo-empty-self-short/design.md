## Context

See proposal.md - Why。scene_first 路径优先调用 `compose_contextual_reply`；未命中分支时落入问卷式 open 兜底。`mock.py` 对未覆盖关键词常返回空串。既有「不想动 / 懒得动」不覆盖「不想干」；既有「空落落」覆盖「空落落的 / 心里空了」类，但不覆盖「整个人空了 / 整个人都空了」。

## Goals / Non-Goals

**Goals:**
- ≤12 字「什么都不想干 / 啥也不想干 / 整个人空了」等短句命中专用共情分支
- compose 与 mock 话术对齐，按关键词轻分流
- 既有「不想动」「空落落的」「提不起劲」路径回归通过
- 最小 diff，可测可回滚

**Non-Goals:**
- 不改调度频率、安全策略、avatar、记忆/编排主路径
- 不把「不想干 / 整个人空了」纳入危机关键词
- 不新增 dialogue_quality 场景（基线已 26/26）
- 不扩「心好堵 mock 空串」等旁路缺口（compose 已覆盖；另开 change）
- 不用裸「空了」以免误伤无关短句

## Decisions

1. **关键词**：`不想干`（覆盖「什么都不想干 / 啥也不想干 / 啥都不想干 / 什么也不想干」）；`整个人空了` / `整个人都空了`（或等价：含「整个人」且含「空了」）。不用裸「空了」。
2. **位置**：置于累透了/不想动/没盼头/无所谓了分支之后、短句烦躁 / 通用 open 之前。
3. **分流**：按「不想干」与「整个人空了」轻分流话术；不用「不想动 / 懒得动 / 空落落」专用表述敷衍。
4. **语气**：接住提不起干劲、整个人发空的泄气感，至多一个问句；不以「嗯」开头；不说教；不输出危机热线。
5. **mock**：同步场景分支；`_VENT` / `_user_tone` 补充同关键词。

## Risks / Trade-offs

- [与不想动混淆] 「不想干」≠「不想动」→ 独立分支 + 回归用例
- [危机误报] 「不想干」口语 ≠「不想活」→ 不改 `safety.py`
- [「空了」过宽] 仅匹配「整个人空了 / 整个人都空了」，不用裸「空了」
- [话术混搭] 单池乱抽 → 按关键词分流
