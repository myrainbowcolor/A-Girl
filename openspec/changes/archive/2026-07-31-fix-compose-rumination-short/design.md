## Context

既有「短句低落倾诉」分支覆盖难过/委屈/崩溃/绝望/失望等关键词，但不含「内耗 / 心态崩 / 心态炸 / 被掏空」。见 proposal.md - Why。

## Goals / Non-Goals

**Goals**
- 短句内耗/心态崩/心态炸/被掏空走既有短句低落共情接话，不问卷兜底
- mock `_VENT` / 情绪低落路径对齐，避免空回复
- 最小 diff：扩展关键词，不新建独立话术池（与失望/破防扩展同一模式）

**Non-Goals**
- 不单独新建「内耗」专用长叙事分支
- 不扩展「好丢脸 / 社恐 / 被裁 / 表白被拒」等其他缺口
- 不改调度频率、安全策略、记忆召回、avatar 映射

## Decisions

1. **并入短句低落关键词表**：在 `compose_contextual_reply` 的 ≤12 字低落分支追加「内耗」「心态崩」「心态炸」「心态爆炸」「被掏空」；复用既有共情话术池。
2. **mock 对齐**：将同五词加入 `_VENT`，并纳入 `_scene_reply` 情绪低落关键词（及 `_user_tone` negative 若需要），使 mock 走共情而非空串。
3. **不拆独立分支**：与「失望/破防」扩展一致，降低话术漂移与抢占风险。

## Risks / Trade-offs

- [「心态炸」误伤含「心态」+「炸」但语义不同的长句] → ≤12 字短句约束；且「心态炸了/心态爆炸」口语几乎专指心态崩溃
- [陌生关系过度亲昵] → 复用既有克制陪伴话术，不强制 intimate 前缀

## Migration Plan

纯后端逻辑扩展，无 DB/API 变更。回滚即 revert compose/mock 改动。
