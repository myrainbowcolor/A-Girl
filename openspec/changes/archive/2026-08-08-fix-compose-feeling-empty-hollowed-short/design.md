## Context

既有「整个人空了」短句分支（compose / mock）用「整个人」+「空了」双条件避免裸「空了」误伤；「被掏空」落在通用短句低落词表。用户常说「感觉空了」「掏空了」时两处均 miss。上一轮已修「堵得慌」mock 对齐，本轮按记忆优先补发空/掏空短句。

## Goals / Non-Goals

**Goals:**
- ≤12 字「感觉空了」「掏空了」（及常见变体）compose 与 mock 共情接住
- 与既有「整个人空了」「被掏空」「空落落」路径兼容
- 最小 diff；pytest + dialogue quality 全绿

**Non-Goals:**
- 不改 safety / 危机词表
- 不扩「心塞」「没意思了 mock」「空虚 mock」（留待后续）
- 不改主动沟通频率、avatar、API/DB
- 不启用裸「空了」匹配

## Decisions

1. **扩展既有分支而非新建并行分支**：在「不想干 / 整个人空了」块内增加 `感觉空了` / `掏空了` 条件，复用发空话术（与「整个人空了」同类），「不想干」仍分流。
2. **不用裸「空了」**：仅用完整短语「感觉空了」「掏空了」，与既有安全约定一致。
3. **长度 ≤12**：与既有短句倾诉约定一致；「工作把我掏空了」仍由更早工作话题分支优先。
4. **`_VENT` / `_user_tone` 补词**：避免 mock 未命中场景分支时落入中性空串。
5. **「被掏空了」可走本分支**：含子串「掏空了」，话术更贴切；「被掏空」无「了」仍走通用低落词表。

## Risks / Trade-offs

- 「掏空了」可能与「被掏空」通用分支重叠 → 可接受，专用话术更拟真
- 误伤风险：避免裸「空了」；单测覆盖「空了」「空落落的」「整个人空了」回归
