## Context

See proposal.md - Why。既有短句慌张/担心分支关键词为「慌」「害怕」「好怕」「担心」「好担心」，不含「怕了」。`mock.py` `_empathy_reply` 用 `("严厉", "耽误", "害怕", "考")` 判定育儿焦虑，导致无语境「好害怕」误套家长话术；`_scene_reply` 亦缺少与 compose 对齐的短句慌张分支，「好怕」「怕了」常返回空串。

## Goals / Non-Goals

**Goals:**
- ≤10 字「怕了」短句命中慌张共情
- 无育儿语境的「害怕/好害怕」mock 走慌张共情，不套家长话术
- compose 与 mock 对齐；既有育儿焦虑与「慌/好担心」回归通过
- 最小 diff，可测可回滚

**Non-Goals:**
- 不改调度频率、安全策略、avatar、记忆/编排主路径
- 不扩「心灰/心死/麻了」等其他缺口
- 不新增 dialogue_quality 场景（基线已 26/26）

## Decisions

1. **关键词扩展**：compose 慌张分支追加「怕了」（「我怕了」自然命中）；不单独加「怕」以免误伤「恐怕」「害怕」分流逻辑外的长句。
2. **mock 育儿判定收紧**：`_empathy_reply` 育儿分支仅在含「孩子/儿子/女儿/太严厉/耽误/考不好」等育儿语境时命中；「害怕」单独不再触发家长话术。
3. **mock 场景分支**：在育儿焦虑之后、通用兜底之前新增 ≤10 字慌张短句分支（与 compose 关键词对齐），保证 scene_first 与 empathy 路径均覆盖。
4. **_VENT**：追加「怕了」「好怕」，使「怕了」能进入倾诉路径作兜底。

## Risks / Trade-offs

- [单独「怕」过宽] → 仅匹配「怕了」「好怕」「害怕」等明确短语
- [育儿场景漏检] → 保留「耽误」「孩子」等语境词；回归「害怕耽误孩子」类用例
- [话术混搭] → 复用既有慌张话术池，不新建无关语气
