## Context

既有「节日孤独 / 想家」分支仅在用户话含「落寞 / 团圆 / 过年 / 一个人」时触发；单独短句「想家了」「想爸妈」等返回 `None`，scene_first 编排落入问卷式 open 兜底。想念/好久未见分支关键词为「想你 / 想念 / 好久不见」等，不覆盖「想家」。见 proposal.md - Why。

## Goals / Non-Goals

**Goals**
- 短句想家/思乡走共情陪伴接话，不问卷兜底
- mock 与 compose 行为一致
- 与节日孤独、想念分支互不抢占

**Non-Goals**
- 不改既有节日孤独分支触发条件（落寞/团圆/过年/一个人）
- 不扩展到长叙事（「一个人在外地读大学三年没回家」）
- 不改调度频率、安全策略、记忆召回、avatar 映射

## Decisions

1. **独立短句 compose 分支**：关键词「想家」「想爸妈」「想回家」「想父母」；`len(text) <= 12`；放在节日孤独分支附近（之后或之前均可，因关键词不交叉）、通用 open 之前；话术侧重思念与空落，不假热闹转移话题。
2. **不并入节日分支**：避免「想家了」被迫套「过节一个人」话术；短句想家与节日孤独语境不同。
3. **与「想你」分支隔离**：关键词不含「想你/想念」，「想回家」含「想」但不会命中想念分支条件。
4. **mock 对齐**：在 `_scene_reply` 节日孤独附近增加同关键词短句分支。

## Risks / Trade-offs

- [「想回家」过宽（如「好想回家吃饭」>12 字不命中）] → 本轮仅覆盖 ≤12 字短句，长句交给 LLM
- [与节日孤独话术相似] → 可接受；短句分支不提「过节」，避免语境错位
- [陌生关系过度亲昵] → 话术保持克制陪伴，不强制 intimate 亲昵前缀

## Migration Plan

纯后端逻辑扩展，无 DB/API 变更。回滚即 revert compose/mock 改动。
