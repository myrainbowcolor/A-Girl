## Context

既有「比较 / 自我怀疑」分支覆盖「升职 / 原地踏步 / 差劲 / 不如」，但不含「自卑」。见 proposal.md - Why。上一轮 `fix-compose-shame-social-anxiety-short` 明确未扩此缺口，本轮单点补齐。

## Goals / Non-Goals

**Goals**
- ≤12 字自卑短句走自我怀疑共情接话，不问卷兜底
- mock 场景路径对齐，避免空回复
- 自卑话术独立分流，避免套用「升职比较 / 原地踏步」话术

**Non-Goals**
- 不扩展「被裁 / 被鸽 / 愧疚 / 摆烂 / 好没用误路由」等其他缺口
- 不改调度频率、安全策略、记忆召回、avatar 映射
- 不新建独立长叙事分支；不改动 impulse spending「没用」分支

## Decisions

1. **扩展既有比较/自我怀疑分支**：在 `compose_contextual_reply` / mock 场景分支关键词追加「自卑」；当文本含「自卑」时走专用话术（先承认自卑感真实、不急着反驳或灌鸡汤），否则保持既有升职/差劲分流。
2. **≤12 字约束**：仅短句触发自卑专用路径，与既有短句低落/社交尴尬模式一致；长句若同时含比较词仍可走既有比较分支。
3. **mock 对齐**：mock 同关键词分支同步；`_VENT` / `_user_tone` 已含「自卑」，无需重复添加，但场景分支必须命中以免空串。

## Risks / Trade-offs

- [「自卑」出现在长叙事中] → ≤12 字短句约束；长句可继续靠通用负面/其他分支
- [与「差劲」分支抢占] → 分流时先判「自卑」再判「差劲」，避免混用比较追问

## Migration Plan

纯后端逻辑扩展，无 DB/API 变更。回滚即 revert compose/mock 改动。
