## Context

`compose_contextual_reply` 是 scene_first 编排的优先无 LLM 接话路径。既有「考试/学业焦虑」分支覆盖考前紧张（高考/考试/紧张/记不住等），但探测发现考后失利短句「考砸了」「没考好」「挂科了」返回 `None`，落入问卷式 open 兜底，缺少先接住挫败感的共情。默认受众为未成年人/学生，该缺口直接影响情感陪伴拟真度。

## Goals / Non-Goals

**Goals**
- 在通用 open 兜底之前新增短句考试失利分支，先接住挫败/失落，至多一个轻问
- 与考前焦虑、家长育儿焦虑分支互不抢占
- mock 场景分支与 compose 对齐

**Non-Goals**
- 不改考前焦虑分支话术或触发词
- 不扩展到「成绩出来了」「排名掉了」等长语境叙事
- 不改调度频率、安全策略、记忆召回、avatar 映射

## Decisions

1. **独立短句分支**：不并入考前焦虑关键词——考前是「紧张绷着弦」，考后是「砸了/挂了」的挫败；专属回复更贴切（「考砸的时候最容易骂自己」「先别急着否定自己」）。
2. **匹配范围**：`len(text) <= 12` 且含「考砸」「没考好」「挂科」任一；排除含「孩子/儿子/女儿」的家长视角，避免抢育儿焦虑分支。
3. **放置位置**：在考试焦虑与育儿焦虑分支之后、通用 open / 短句低落之前，确保「考砸了」不被考前话术误接。
4. **mock 对齐**：在 `_scene_reply` 增加同关键词短句分支，语气与 compose 一致。

## Risks / Trade-offs

- [「没考好」与育儿「考不好」混淆] → 排除家长关键词；「没考好」不含「考不好」子串，不误触育儿分支
- [长句含「挂科」误伤] → 限制 len≤12，长句仍走其他场景/LLM

## Migration Plan

纯后端逻辑扩展，无 DB/API 变更。回滚即 revert compose/mock 改动。
