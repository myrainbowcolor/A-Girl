## Context

See proposal.md - Why。scene_first 路径优先调用 `compose_contextual_reply`；未命中分支时落入问卷式 open 兜底。`mock.py` 对未覆盖关键词常返回空串。既有「撑不住/扛不住/受不了/绷不住」不覆盖「受够了」；短句低落关键词不含「心凉」「寒心」。

## Goals / Non-Goals

**Goals:**
- ≤12 字心凉/寒心/受够了短句命中专用共情分支
- compose 与 mock 话术对齐
- 既有撑不住与短句低落路径回归通过
- 最小 diff，可测可回滚

**Non-Goals:**
- 不改调度频率、安全策略、avatar、记忆/编排主路径
- 不扩「怕了」或其他未点名缺口（好害怕已有慌张分支）
- 不新增 dialogue_quality 场景（基线已 26/26）

## Decisions

1. **关键词**：`心凉` / `寒心` / `受够了`（整词匹配受够了，避免与「受不了」混淆）。
2. **位置**：置于「撑不住/受不了」分支之后、通用 open 兜底之前；「快撑不住了」仍由既有分支命中。
3. **分流**：按「受够了」「心凉/寒心」轻分流话术，避免单一 `_pick` 混搭导致「受够了」抽到「心凉」话术。
4. **语气**：接住心凉/寒心的失望感或受够了的耗竭感，至多一个问句；不以「嗯」开头；不说教。

## Risks / Trade-offs

- [与受不了混淆] 「受够了」≠「受不了」→ 用整词「受够了」，不匹配单独「受」
- [话术混搭] 单池乱抽 → 按关键词分流
- [关键词过宽] 限制 ≤12 字，降低误伤长句
