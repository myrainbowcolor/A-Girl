## Context

See proposal.md - Why。scene_first 路径优先调用 `compose_contextual_reply`；未命中分支时落入问卷式 open 兜底。`mock.py` 对未覆盖关键词常返回空串。既有「没救」不匹配「废了」；「提不起劲 / 提不起精神」不匹配「提不起兴趣」；「心累」不单独覆盖「完了 / 完蛋」口语。

## Goals / Non-Goals

**Goals:**
- ≤12 字废了/好废/完了（整句精确）/我完了/完蛋/提不起兴趣短句命中专用共情分支
- compose 与 mock 话术对齐，按关键词轻分流
- 「做完了」等完成义短句不因「完了」子串误入
- 既有「没救了」「提不起劲」路径回归通过
- 最小 diff，可测可回滚

**Non-Goals:**
- 不改调度频率、安全策略、avatar、记忆/编排主路径
- 不把「废了 / 完了」纳入危机关键词（避免误报热线）
- 不新增 dialogue_quality 场景（基线已 26/26）
- 不扩「累透了 / 不想动 / 没盼头」等其他未点名缺口

## Decisions

1. **关键词**：`废了` / `好废` / `完蛋` / `我完了` / 整句精确 `完了` / `提不起兴趣`。不用裸子串「完了」匹配（避免「做完了」「写完了」误伤）。
2. **位置**：置于没救了/凉透了/提不起劲分支之后、短句烦躁 / 通用 open 之前。
3. **分流**：按「废了/好废」「完蛋/我完了/整句完了」「提不起兴趣」轻分流话术，避免单一 `_pick` 混搭。
4. **语气**：接住自我否定泄气、完蛋感或提不起兴趣的无力感，至多一个问句；不以「嗯」开头；不说教；不输出危机热线。
5. **mock**：同步场景分支；`_VENT` / `_user_tone` 补充同关键词（`_VENT` 用「废了」「好废」「完蛋」「我完了」「提不起兴趣」，整句「完了」由场景分支精确匹配）。

## Risks / Trade-offs

- [危机误报] 「完了 / 废了」口语 ≠ 自伤 → 不改 `safety.py`，话术走陪伴共情
- [「完了」过宽] 仅整句精确「完了」或「我完了」「完蛋」，不用裸子串「完了」
- [与提不起劲重叠] 「提不起兴趣」独立分支，勿依赖「提不起劲」子串；既有「提不起劲」回归保留
- [与没救重叠] 「废了」独立话术，勿套用「没救」表述
- [话术混搭] 单池乱抽 → 按关键词分流
